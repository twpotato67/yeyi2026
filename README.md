# 自動摺衣板

發明展作品。按下 A 鍵，三片摺板依序由伺服馬達翻起、放下，把衣服摺好。

## 硬體

| 零件 | 說明 |
|---|---|
| M5Stack Basic V2.7（K001-V27） | 主控板，USB 晶片是 CH9102F |
| Module13.2 Servo2 | PCA9685 晶片，I2C 位址 0x40（G21/G22），疊在 Basic 下面 |
| MG996R 360 度 × 3 | 馬達一 → 接口 0、馬達二 → 接口 1、馬達三 → 接口 2 |
| 外部電源 | 接 Servo2 的 XT60 接頭，6–12V（見下方「供電」） |

## 操作

| 狀態 | 按鍵 |
|---|---|
| 待機中 | A：開始摺衣 C：測試模式 |
| 任何時候 | B：緊急停止（三顆馬達立刻停） |
| 緊急停止後 | 把摺板扶回原位，再按 A 重新開始 |
| 測試模式 | A：換馬達 C：讓這顆轉一次 長按 A：停止點校正 長按 C：離開 |
| 停止點校正 | A：-5us C：+5us B：離開 |

## 開發環境（UIFlow 1）

韌體是 `uiflow/main.py`（MicroPython），用 UIFlow 1 上傳，螢幕只能顯示英文。

1. 安裝 CH9102 驅動：<https://docs.m5stack.com/en/download>（找 CH9102_VCP_SER_Windows）
2. 用 USB-C 線接上 M5Stack，開 UIFlow 1 連上板子，選 **Python** 模式
3. 把 `uiflow/main.py` 整份貼上，按下載（Download）

## 調整設定值

所有設定都在 `uiflow/main.py` 開頭的「設定值」區塊，改完要重新貼上並下載。

### 1. 方向
用測試模式讓每顆馬達轉一次。如果摺板往下壓而不是往上翻，就把那顆馬達的 `FOLD_DIR` 改成 `-1`。

### 2. 停止點校正
連續旋轉馬達收到「停止點」脈衝時應該不動，但每顆馬達的停止點都略有不同（約 1450–1550us）。

1. 測試模式下按 A 選好馬達，**長按 A** 進入校正
2. 馬達會收到目前的停止點脈衝。如果在慢慢轉，就按 A 或 C 調整，直到完全不動
3. 不動的範圍通常有好幾個數字，取**中間值**
4. 把數字填回 `NEUTRAL_US`，重新上傳

程式在「停止」時完全不送脈衝，所以停止點不準也不會讓馬達亂爬。校正的目的是讓兩個方向的速度一樣。

### 3. 轉動時間
1. 先調 `FOLD_MS`：用測試模式反覆轉，調到翻起剛好 180 度
2. 再調 `RETURN_MS`：放下時有重力幫忙，通常要比翻起短一點，調到剛好回到原位
3. 板子上放一件衣服再調一次，因為衣服的重量會改變速度

## 只靠時間控制的誤差

每次「翻起」和「放下」的角度只要差一點點，摺越多次就偏越多。造成誤差的原因有：

- **重力**：翻起時要抬起摺板和衣服，放下時有重力幫忙，所以速度不一樣（用 `FOLD_MS`／`RETURN_MS` 分開調）
- **負載和溫度**：衣服的重量、齒輪的摩擦和馬達的溫度，都會讓速度每次稍微不同（Servo2 會把電源穩壓到 5V，所以電源電壓的影響比較小）
- **訊號更新頻率**：伺服訊號每 20ms 才送一次，時間精度大約是 ±20ms，相當於 ±12 度

改善方法（由簡單到可靠）：

1. 翻起和放下的時間分開調（程式已支援）
2. **機械擋塊**：在原位放一塊擋板，放下時間故意多給一點，讓摺板「靠」在擋板上。每次都會回到同一個位置，等於自動歸零。這個方法不用改程式，最推薦。
3. 原位裝微動開關或霍爾感測器，回程時轉到觸發開關才停（要加配線和程式）
4. 改用 MG996R 180 度版（一般角度伺服馬達），直接指定角度，完全沒有累積誤差

展覽時，每摺幾件就檢查一次摺板有沒有回到原位。

## 供電

- **馬達電源不能靠 USB**，一定要從 Servo2 的 XT60 接頭接 **6–12V** 外部電源。模組會把它降成 5V 給馬達。
- MG996R 每顆正常轉動約 0.5–1A，卡住時可達 2.5A。建議電源要有 **3A 以上**：
  - 方案 A：**12V 3A（或 7.5V 3A 以上）變壓器**＋DC 轉 XT60 轉接線，適合展覽時插電使用，電壓也最穩定
  - 方案 B：**2S 7.4V 鋰電池（XT60 接頭）**，方便移動，但要買專用充電器，也要注意不能過放
- 接線前先確認正負極，XT60 有防呆設計，但自製的轉接線要特別小心
- 在電源線上加一個開關，插拔馬達之前先關掉電源
- 馬達卡住（例如被衣服纏住）時，請立刻按 B 停止，否則馬達會發燙
- 程式開機時不會送任何脈衝，所以一通電馬達不會亂轉

## 手機／電腦 app（模擬模式，尚未連 M5Stack）

雨衣清洗＋摺衣的站點管理 app，只用 Python 內建模組，不用安裝套件。

```
python app/server.py
```

- 電腦：瀏覽器開 <http://localhost:8000>
- 手機：連同一個 WiFi，開畫面上印出的第二個網址（例如 `http://192.168.x.x:8000`）
- 流程：放入雨衣 → 清洗（預設 120 秒）→ 按「已移到摺衣站」→ 摺衣（馬達 1→2→1→3）→ 取件
- 緊急停止：全站立刻停；解除後可「重試」。
- 設定值在 `app/server.py` 開頭。測試時可加速：`SIM_SPEED=20 python app/server.py`，或縮短清洗：`WASH_SECONDS=10 python app/server.py`
- M5Stack 完成後，把 `app/server.py` 的 `SimulatedDriver` 換成 `M5Driver`（WiFi 呼叫）即可。
